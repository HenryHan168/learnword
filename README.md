# 🌟 LearnWord - 學前兒童英文學習App

## 📱 專案簡介

LearnWord 是一款專為 3-6 歲學前兒童設計的英文單字和短句學習應用程式。透過豐富的圖像、互動式學習和獎勵機制，讓孩子在遊戲中快樂學習英文。

## 🎯 核心功能

### 1. 多類別學習
- 🐶 **動物類** (Animals): 常見動物單字
- 🎨 **顏色類** (Colors): 基礎顏色認知
- 🔢 **數字類** (Numbers): 1-10 數字學習
- 🍎 **水果類** (Fruits): 常見水果單字
- ⚽ **日常用品** (Daily Items): 生活常見物品
- 💬 **簡單短句** (Simple Phrases): 日常用語

### 2. 互動學習模式
- **圖片展示**：✅ 已啟用！可愛的 emoji 表情符號，視覺化學習
- **語音發音**：✅ 已啟用！標準美式英語發音，可重複播放
- **發音驗證**：🚀 即將推出！使用語音識別檢測發音準確度
- **觸控互動**：簡單的點擊操作，適合兒童
- **即時反饋**：動畫和聲音效果增強學習體驗

### 3. 測驗系統 🆕
- 📝 **多種題型**：看圖選單字、聽音選圖、拼字練習
- 🎲 **隨機出題**：從選定類別中隨機抽取題目
- 📊 **即時統計**：答對率、學習曲線追蹤
- 🏅 **錯題複習**：自動收集錯題，重點加強
- ⭐ **獎勵機制**：測驗達標獲得額外星星

### 4. 獎勵系統
- ⭐ 完成學習獲得星星
- 🎉 達成里程碑顯示慶祝動畫
- 📊 學習進度追蹤
- 🏆 成就徽章收集

### 5. 付費功能 💎
- **免費版**：30個基礎單字，基本測驗功能
- **付費版**：
  - 📚 完整58+單字庫
  - ➕ 自訂類別和單字
  - 🎤 無限發音驗證
  - 📝 進階測驗模式
  - ❌ 無廣告體驗

## 📖 使用說明

### 給家長
1. 首次開啟 App 會看到主畫面，顯示所有學習類別
2. 點擊任一類別進入單字列表
3. 點擊單字卡片開始學習
4. 鼓勵孩子點擊喇叭圖標聽發音並跟讀
5. 完成學習後會獲得星星獎勵

### 給孩子
- 🏠 點擊你喜歡的圖片
- 👂 按喇叭聽聽看
- 👄 跟著說說看
- ⭐ 收集更多星星

## 🔧 安裝與運行

### 系統需求
- macOS 14.0 (Sonoma) 或更高版本
- Xcode 15.0 或更高版本
- iOS 17.0+ 實體設備或模擬器

### 運行步驟
1. 使用 Xcode 開啟 `learnWord.xcodeproj`
2. 選擇目標設備（iPhone 或 iPad 模擬器）
3. 按下 `Cmd + R` 運行專案

## 🎯 教育理念

### 設計原則
- **主動學習**：鼓勵孩子主動點擊探索
- **即時回饋**：每個動作都有明確反饋
- **正面鼓勵**：只有獎勵，沒有懲罰
- **重複練習**：可以無限次重複學習
- **自主節奏**：孩子可以按自己的速度學習

### 學習建議
- 每次學習時間：10-15 分鐘
- 建議頻率：每天 1-2 次
- 家長陪伴：建議初期陪同使用
- 重複學習：多次復習加深記憶
